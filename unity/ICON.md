# Discontinuity Icon

The application and desktop shortcut use `Assets/Resources/DiscontinuityIcon.png`. The Windows build embeds the artwork and exports a seven-size `Discontinuity.ico` (16 through 256 pixels). The shortcut uses that ICO directly, avoiding the cached Unity executable icon.

Generated using the built-in image generation tool, then copied into this project. No creative edits were applied; build-time resizing and ICO encoding package it for Windows.

## Generation Prompt

Create a finished desktop game application icon for Discontinuity, a turn-based social mystery about reliving the same morning. Square 1024x1024 composition. A single vivid cobalt-blue sealed envelope in the center, encircled by a broken ivory/silver clock ring with two slightly offset arc segments, suggesting an interrupted day. Bold clean silhouette that remains legible at 32px. Restrained enamel and engraved-metal illustration, subtle depth, precise edges, sophisticated mystery-game identity. Deep charcoal-green background filling the square. Envelope and ring occupy about 80% of the image with generous uniform outer margin. No text, no letters, no clock numerals, no people, no extra objects, no watermark, no Unity logo. Produce one icon, not a mockup or an icon sheet.
